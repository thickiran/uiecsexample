DRAG & DROP SYSTEM DETAILS:
===========================

DRAG OPERATION FLOW:
1. OnBeginDrag():
   - Store original position
   - Set opacity to 60% (dragAlpha = 0.6)
   - Disable raycasts (blocksRaycasts = false)
   - Set isDragging = true

2. OnDrag():
   - Move slot to follow mouse cursor
   - Item visually follows mouse movement

3. OnEndDrag():
   - Restore original position
   - Restore full opacity (alpha = 1.0)
   - Re-enable raycasts (blocksRaycasts = true)
   - Process drop logic
   - Set isDragging = false

DROP VALIDATION LOGIC:
1. Empty Target Slot:
   - Move item completely to target slot
   - Clear source slot

2. Same Item Type (Stacking):
   - Calculate available stack space
   - Move items up to maximum stack size
   - Update stack counts appropriately
   - Clear source if all items moved

3. Different Item Type (Swapping):
   - Exchange items between slots
   - Preserve stack counts
   - Update both slots simultaneously
